🗑 Remove Item

Permanently deletes all PriceLog history for this item and removes it from PriceInfo.

You can copy names from PriceInfo — the sheet stays interactive while this sidebar is open.

🔀 Merge Items

Rewrites all PriceLog entries for the source name to the target name, then rebuilds PriceInfo.

Copy names from PriceInfo while the sidebar is open.

🚀 Push to Site

Sends the sheet data to GitHub now instead of waiting for the 10-minute idle timer. The site updates ~2–3 minutes later.
